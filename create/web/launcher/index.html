Subir anúncios no Taboola

AdHunters Create. Gere ou envie imagens e headlines, escolha as que valem, combine e baixe a planilha e as imagens para o Bulk Upload do Taboola. Nada é enviado ao Taboola daqui.

1. Briefing

A IA separa o que é fixo do que varia (pessoa, gesto, produto, cenário, enquadramento, emoção, estilo da foto) e cria imagens novas nesse padrão: metade variações próximas, metade ângulos novos. Esses anúncios não vão para o gerador de imagens.

Vai junto para o gerador, para o produto aparecer igual em todas as imagens.

2. Criativos

Marque as imagens que vão para a campanha. Também dá para enviar as suas.

3. Headlines

Marque as headlines que vão para a campanha. Dá para editar o texto aqui mesmo.

5. Campanha

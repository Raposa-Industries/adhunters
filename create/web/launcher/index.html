6. Anúncios

7. Baixar e subir

  1. No Taboola (Realize): Create › Bulk Upload.
  2. Envie a planilha (os anúncios ficam na aba Ads; a aba Campaigns fica vazia de propósito, porque eles entram em campanhas que já existem). Quando pedir, envie o .zip das imagens: os nomes batem com a coluna Image File Name.
  3. Confira o relatório de processamento. Os anúncios entram na revisão do Taboola.
  4. Marque “AI content” nesses anúncios no Realize se a planilha não tiver essa opção.
  5. Se o Taboola recusar a planilha, baixe o modelo dele (Download Template), clique em Copiar linhas e cole na aba Ads, abaixo do cabeçalho.

# 0006 · App names: Spy, Create, Intel, Funnels, Raposa

**Decided:** 28 Sep 2026, by Marcos.

The apps people use are AdHunters Spy (research; was adhunters-v4), AdHunters
Create (images and headlines; was auto-creative), AdHunters Intel (our
campaigns' performance), AdHunters Funnels (landing pages and visitors) and
AdHunters Raposa (dark funnel forensics). Code folders and database schemas
use the same plain names: `spy/`, `create/`, `intel/`, `funnels/`, `raposa/`.
Collection stays `tracks/`, internal with no app, and the design system stays
Ember. The design's themed names (Scout, Forge, Compass, Lure) are retired.

**Why:** plain names say what each app is to the whole team, and one name per
thing in the UI, the folder and the schema leaves nothing to translate.
